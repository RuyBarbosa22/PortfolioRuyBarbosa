# Frontend - Portfólio Ruy Barbosa 🎨

Frontend do portfólio pessoal de Ruy Barbosa de Castro com chatbot inteligente (Menebot).

## 🚀 Tecnologias

- **React 19** - Framework UI
- **TypeScript 5.9** - Linguagem
- **Vite 7.1** - Build tool
- **Tailwind CSS 4.1** - Styling
- **Socket.io-client 4.8** - WebSocket

## 📦 Novos Componentes

### MenebotChat.tsx
Interface completa do chat com Menebot.

### ChatWithMenebot.tsx (Atualizado)
Validação de email e integração com chat.

## ⚙️ Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Acesse: http://localhost:5173
